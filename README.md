# Estimating effectiveness of measles supplementary immunization activities via discrete-time modeling of disease incidence time series

Here are some example R code for the model implementation in "Estimating effectiveness of measles supplementary immunization activities via discrete-time modeling of disease incidence time series" by Dong and Wakefield (2026). 

- *a_functions.R*: R code for defining and saving essential functions. 

- *b_stage_1.R*: R code for conducting the first stage of computation: reporting rate estimation.

- *c_stage_2.R*: R code for conducting the second stage of computation: estimating the other model parameters.

- *d_summary.R*: R code for summarizing estimation results.

- *cov_logit_theta_gamma12_mt.rds*: covariance matrix to be used for the second stage of computation.

- *example_data.RData*: example data to test run the example R scripts.

Please run the R scripts in order (i.e., a, b, c, d) to test run the code.
